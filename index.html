Tools

Localization QA

Available now

Finds the localization bugs players post screenshots of: text that won't fit its box, letters your font can't show and strings nobody translated.

It checks TextMeshPro, legacy Text and UI Toolkit, reads Unity Localization string tables, and runs from the command line on build servers.

Get it on the Asset Store

Procedural Motion

Try the demo

Spring-based motion for Unity: UI, cameras and characters that follow, overshoot and settle naturally, tuned with a live response graph in the Inspector.
